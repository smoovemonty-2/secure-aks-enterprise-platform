What is Microsoft Defender for Cloud?
  Defender for Cloud provides continuous cloud security posture management (CSPM), workload protection, recommendations, threat detection, and compliance monitoring across
  supported cloud resources.
What is Secure Score?
  Secure Score provides a numeric value which is an indicator of your current security posture and helps you prioritize security improvements based on Microsoft's recommended
  best practices.
How is Defender for Cloud different from Microsoft Sentinel?
  Defender for Cloud assesses your security posture, identifies weaknesses, and helps prioritize remediations while Sentinel is a SIEM/SOAR platform that records and correlates
  security events, detects potential threats and attacks, and focuses more on monitoring and more immediate responses. These two tools compliment each other rather than replace.
Why should Defender be configured before production workloads?
  This allows for establishing security baselines, detects misconfigurations or weaknesses prior to deploying to production and thus avoiding unnecessary exposures, and allows
  for continuous monitoring from the start of the development lifecycle. 
How does Defender support NIST 800-53 and FedRAMP?
  Defender helps identify weaknesses, supports continuous monitoring, and can map recommendations to regulatory frameworks such as NIST and FedRAMP making acheiving compliance
  a more streamlined process.
