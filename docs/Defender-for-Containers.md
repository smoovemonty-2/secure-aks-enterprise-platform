We enabled Defender for Containers in Defender for Cloud to protect our Kubernetes clusters.
The use case is for Azure Kubernetes Service (AKS) to allow for vulnerability assessments, identifying misconfigurations, runtime threat detections, etc.
This helps with a zero trust environment as it can ensure that no container, image, or cluster is trusted by default and enforces security at every level. 
Components include:
  Defender Plan
  Defender Sensor
  Azure Policy
  Runtime Protection
  Vulnerability Assessment
  CSPM
  Secure Score
  Regulatory Compliance
How does Defender for Cloud differ from Sentinel?
  Defender for Cloud evaluates your overall security posture, provides recommendations, looks at compliance within different frameworks such as NIST, FedRAMP, etc. It is designed to protect your cloud workloads and assets.
  Sentinel is a SIEM that is designed to ingest data with long-term logs and ciritcal alerts for threat analysis, investigations, and auditing.
